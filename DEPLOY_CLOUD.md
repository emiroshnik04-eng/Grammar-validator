# Развертывание в облаке (бесплатно)

Инструкция по развертыванию Catalog Validator на бесплатных облачных платформах.

---

## Вариант 1: Render.com (САМЫЙ ПРОСТОЙ) ⭐

**Преимущества:**
- Полностью бесплатно навсегда
- Автоматический деплой из GitHub
- SSL сертификат (HTTPS)
- Простая настройка

**Недостатки:**
- Засыпает после 15 минут неактивности
- Первый запрос после сна медленный (~30 сек)

### Шаг 1: Подготовка GitHub репозитория

1. Создайте репозиторий на GitHub (если еще нет)
2. Загрузите туда весь проект:

```bash
cd d:\TestProject
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/catalog-validator.git
git push -u origin main
```

**ВАЖНО:** Не коммитьте файл `.env` с API ключом! Он уже в `.gitignore`

### Шаг 2: Регистрация на Render.com

1. Перейдите на https://render.com
2. Нажмите **Sign Up**
3. Зарегистрируйтесь через GitHub (рекомендуется)

### Шаг 3: Создание Web Service

1. В панели управления нажмите **New +**
2. Выберите **Web Service**
3. Подключите ваш GitHub репозиторий
4. Настройки:
   - **Name:** `catalog-validator` (или своё название)
   - **Region:** `Frankfurt` (ближайший к вам)
   - **Branch:** `main`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python web_app.py`
   - **Plan:** `Free`

### Шаг 4: Настройка переменных окружения

В разделе **Environment Variables** добавьте:

```
OPENAI_API_KEY = sk-ваш-ключ-здесь
SERVER_HOST = 0.0.0.0
SERVER_PORT = 8080
ENVIRONMENT = production
```

### Шаг 5: Деплой

1. Нажмите **Create Web Service**
2. Подождите 3-5 минут пока происходит сборка
3. Готово! Ваш URL: `https://catalog-validator.onrender.com`

### Автоматические обновления

При каждом push в GitHub - автоматический редеплой!

## Вариант 2: Fly.io (НЕ ЗАСЫПАЕТ)

**Преимущества:**
- Бесплатный tier
- Не засыпает (всегда готов к работе)
- Быстрый
- Хорошая документация

**Недостатки:**
- Немного сложнее настроить
- Требует установки CLI

### Шаг 1: Установка Fly CLI

**Windows:**
```powershell
powershell -Command "iwr https://fly.io/install.ps1 -useb | iex"
```

**Mac/Linux:**
```bash
curl -L https://fly.io/install.sh | sh
```

### Шаг 2: Регистрация и вход

```bash
fly auth signup
# или если уже есть аккаунт:
fly auth login
```

### Шаг 3: Подготовка проекта

```bash
cd d:\TestProject
fly launch
```

Отвечайте на вопросы:
- **App Name:** catalog-validator (или своё)
- **Region:** fra (Frankfurt)
- **Deploy now?** No

### Шаг 4: Установка секретов

```bash
fly secrets set OPENAI_API_KEY=sk-ваш-ключ-здесь
```

### Шаг 5: Деплой

```bash
fly deploy
```

Подождите 2-3 минуты. Ваш URL: `https://catalog-validator.fly.dev`

### Обновление приложения

```bash
fly deploy
```

URL: `https://catalog-validator.up.railway.app`

## Решение проблемы засыпания Render.com

Если Render.com засыпает и это проблема:

### Вариант 1: UptimeRobot (бесплатно)

1. Зарегистрируйтесь на https://uptimerobot.com
2. Добавьте мониторинг вашего URL
3. Установите проверку каждые 5 минут
4. Сервис будет "будить" ваше приложение

### Вариант 2: GitHub Actions (бесплатно)

Создайте файл `.github/workflows/keep-alive.yml`:

```yaml
name: Keep Alive
on:
  schedule:
    - cron: '*/14 * * * *'  # Каждые 14 минут
jobs:
  keep-alive:
    runs-on: ubuntu-latest
    steps:
      - name: Ping
        run: curl https://catalog-validator.onrender.com
```

## Резервное копирование

Все платформы хранят код в Git - это уже резервная копия.

Для резервного копирования данных (загруженные файлы):
- Файлы удаляются при перезапуске
- Это нормально для валидатора (одноразовые операции)
- Результаты скачиваются сразу
