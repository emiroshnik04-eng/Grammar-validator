🚀 ЗАПУСК СЕРВЕРА:

  Способ 1: Дважды кликните на файл start.bat
  Способ 2: Откройте командную строку и выполните:
           cd d:\TestProject
           python web_app.py

📱 ИСПОЛЬЗОВАНИЕ:

  1. После запуска откроется окно консоли с логами
  2. Откройте браузер по адресу: http://127.0.0.1:8080
  3. Нажмите кнопку "Выбрать файл"
  4. Выберите ваш CSV файл каталога
  5. Нажмите "Проверить каталог"
  6. Дождитесь завершения обработки
  7. Скачайте результат (Excel файл)

✨ ЧТО ПРОВЕРЯЕТСЯ:

  • Формат категорий (именительный падеж, множественное число)
  • Орфография и грамматика
  • Согласование параметров и значений
  • Умный анализ через OpenAI GPT-4 (если настроен)

🤖 УМНЫЙ АНАЛИЗ (LLM):

  ✅ УЖЕ НАСТРОЕН И РАБОТАЕТ!

  🚀 Оптимизация с кэшированием:
  • Каждая уникальная категория проверяется только 1 раз
  • Результаты сохраняются в кэш
  • Файл на 1500 строк → проверяется за 30-60 секунд
  • При повторных проверках → мгновенно из кэша!

  💡 Пример:
  1-я проверка: 50 уникальных категорий → 50 API запросов
  2-я проверка: всё из кэша → 0 запросов → мгновенно!

  📖 Подробнее: см. файл ОПТИМИЗАЦИЯ_LLM.txt

🎯 РЕЗУЛЬТАТ:

  Excel файл с:
  • Исходными данными
  • Предложениями по исправлению (в колонках __correct)
  • Комментариями (в колонках __comment)
  • Подсветкой ячеек с ошибками

⏹️ ОСТАНОВКА СЕРВЕРА:

  Нажмите Ctrl+C в окне консоли
