## 🐛 Если тесты не проходят

### UDPipe не устанавливается

**Windows:**
```bash
pip install --upgrade pip
pip install ufal.udpipe conllu
```

**Linux/macOS:**
```bash
pip3 install ufal.udpipe conllu
```

### Модель не загружается

Модель загружается автоматически в `~/.cache/udpipe/`. Если есть проблемы:

1. Проверьте интернет-соединение
2. Скачайте вручную: https://lindat.mff.cuni.cz/repository/xmlui/handle/11234/1-5150
3. Положите в `~/.cache/udpipe/russian-syntagrus-ud-2.12-230717.udpipe`

### Dependency parsing не работает

Проверьте:

```python
from dependency_parser import get_parser

parser = get_parser()
if parser and parser.pipeline:
    print("✅ UDPipe работает")
else:
    print("❌ UDPipe недоступен")
```

Если недоступен - валидация продолжит работу с fallback на pymorphy3.
