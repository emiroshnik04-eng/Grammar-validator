  ОПТИМИЗАЦИЯ LLM АНАЛИЗА - Как это работает
═══════════════════════════════════════════════════════════════

🚀 ПРОБЛЕМА:
  Отправка запроса к OpenAI для каждой строки в файле очень медленная.
  Файл на 1500 строк = 1500 запросов = 10+ минут ожидания.

✅ РЕШЕНИЕ - УМНОЕ КЭШИРОВАНИЕ:

  1️⃣ Собираем УНИКАЛЬНЫЕ категории из файла
     Пример: если "Игрушки" встречается 500 раз - проверяем 1 раз

  2️⃣ Сохраняем результат в кэш
     При повторной встрече "Игрушки" - берём из кэша (мгновенно)

  3️⃣ Кэш работает в рамках одной сессии сервера
     Перезапуск сервера = очистка кэша

📊 РЕАЛЬНАЯ ЭФФЕКТИВНОСТЬ:

  БЕЗ КЭША:
  • 1500 строк, 50 уникальных категорий
  • 1500 запросов к OpenAI
  • ⏱️ Время: ~10 минут

  С КЭШЕМ:
  • 1500 строк, 50 уникальных категорий
  • 50 запросов к OpenAI (только уникальные!)
  • ⏱️ Время: ~30-60 секунд

🎯 КАК ИСПОЛЬЗОВАТЬ:

  1. Запустите сервер: start.bat
  2. Загрузите файл через веб-интерфейс
  3. Первая проверка: будет проверено N уникальных категорий
  4. Повторная проверка: всё берётся из кэша (мгновенно)

📝 ЧТО ВИДИТЕ В ЛОГАХ:

  [LLM] Уникальных категорий: 50
  [LLM] Уже в кэше: 0
  [LLM] Нужно проверить: 50

  После первой проверки:
  [LLM] Уникальных категорий: 50
  [LLM] Уже в кэше: 50
  [LLM] Нужно проверить: 0  ← Мгновенно!

🔄 ОЧИСТКА КЭША:

  • Автоматически: перезапуск сервера
  • Вручную: остановите (Ctrl+C) и запустите заново

⚙️ ДОПОЛНИТЕЛЬНЫЕ ОПТИМИЗАЦИИ:

  ✓ LLM анализ НЕ используется если есть локальные ошибки
    (орфография, формат) - экономим запросы

  ✓ Увеличен timeout до 10 секунд
    (было 5 сек) - меньше ошибок при медленном API

  ✓ Все ошибки LLM не блокируют основную валидацию
    Если OpenAI недоступен - работа продолжается

💡 СОВЕТЫ ПО ИСПОЛЬЗОВАНИЮ:

  1. Если файлы похожи - кэш накапливается
     Проверили 3 похожих каталога? 4-й будет мгновенным!

  2. Для разовых проверок - кэш не критичен
     Но всё равно экономит время на повторяющихся категориях

  3. При работе с большими файлами
     Первая проверка медленнее, все последующие - быстрые

═══════════════════════════════════════════════════════════════
  💰 ЭКОНОМИЯ ДЕНЕГ:

  Меньше запросов к OpenAI = меньше трата токенов
  Файл на 1500 строк:
  • Без кэша: $0.50-1.00
  • С кэшем: $0.02-0.05 (50 уникальных категорий)
