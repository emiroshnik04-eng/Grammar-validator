# Быстрый старт: Render.com (5 минут)

Самый простой способ развернуть Catalog Validator онлайн бесплатно.

---

## Что вам нужно:

1. Аккаунт GitHub (бесплатно)
2. OpenAI API ключ
3. 5 минут времени

---

## Шаг 1: Загрузите код на GitHub (2 минуты)

### Если у вас нет репозитория:

1. Создайте новый репозиторий на https://github.com/new
   - Name: `catalog-validator`
   - Public или Private (на ваш выбор)
   - НЕ добавляйте README

2. Выполните команды:

```bash
cd d:\TestProject

# Инициализируйте Git (если еще не сделано)
git init

# Добавьте все файлы
git add .

# Создайте коммит
git commit -m "Initial commit"

# Подключите удаленный репозиторий
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/catalog-validator.git

# Загрузите код
git push -u origin main
```

**ВАЖНО:** Файл `.env` не загрузится (он в .gitignore) - это правильно!

---

## Шаг 2: Настройте Render.com (3 минуты)

### 2.1 Регистрация

1. Перейдите на https://render.com
2. Нажмите **Get Started for Free**
3. Выберите **Sign Up with GitHub**
4. Разрешите доступ

### 2.2 Создание сервиса

1. В панели управления нажмите **New +**
2. Выберите **Web Service**
3. Нажмите **Connect** рядом с вашим репозиторием
4. Если не видите репозиторий - нажмите **Configure account** и дайте доступ

### 2.3 Настройки

Заполните форму:

**Name:** `catalog-validator` (или своё название)

**Region:** `Frankfurt (EU Central)`

**Branch:** `main`

**Runtime:** `Python 3`

**Build Command:** (автоматически заполнится)
```
pip install -r requirements.txt
```

**Start Command:**
```
python web_app.py
```

**Instance Type:** `Free`

### 2.4 Переменные окружения

Прокрутите вниз до раздела **Environment Variables**

Нажмите **Add Environment Variable** и добавьте:

```
Key: OPENAI_API_KEY
Value: sk-ваш-api-ключ-здесь
```

Добавьте еще три переменные:

```
Key: SERVER_HOST
Value: 0.0.0.0
```

```
Key: SERVER_PORT
Value: 8080
```

```
Key: ENVIRONMENT
Value: production
```

### 2.5 Деплой

1. Нажмите **Create Web Service** внизу страницы
2. Подождите 3-5 минут
3. Статус изменится на **Live** 🟢

## Важные замечания

### Засыпание

После 15 минут неактивности сервис засыпает:
- Первый запрос разбудит его (~30 секунд)
- Последующие запросы быстрые

**Решение:** Используйте [UptimeRobot](https://uptimerobot.com) для автоматического "пробуждения"

### Обновление кода

Когда вы изменяете код:

```bash
git add .
git commit -m "Описание изменений"
git push
```

Render.com автоматически развернет новую версию!

### Логи и мониторинг

В панели Render.com:
- **Logs** - смотрите логи в реальном времени
- **Metrics** - статистика использования

## Если что-то пошло не так

### Ошибка при сборке:

1. Проверьте логи в Render.com
2. Убедитесь что `requirements.txt` загружен в Git
3. Проверьте что все Python файлы на месте

### Приложение не открывается:

1. Проверьте что статус **Live** 🟢
2. Подождите 30 секунд (может спать)
3. Проверьте логи на наличие ошибок

### Ошибка OpenAI API:

1. Проверьте что переменная `OPENAI_API_KEY` установлена
2. Проверьте что ключ действителен
3. Проверьте что на балансе OpenAI есть средства
