  1. БЫСТРЫЙ СТАРТ (для начинающих)
═══════════════════════════════════════════════════════════════════════════

   ► Шаг 1: Создайте ярлык на рабочем столе

     • Дважды кликните на файл:
       "create_desktop_shortcut.bat"

     • На рабочем столе появится ярлык "Catalog Validator"

   ► Шаг 2: Запустите приложение

     • Дважды кликните на ярлык "Catalog Validator"
       на рабочем столе

     • Откроется черное окно консоли (НЕ ЗАКРЫВАЙТЕ ЕГО!)

     • Браузер автоматически откроется через 3 секунды

   ► Шаг 3: Работайте с приложением

     • В браузере нажмите "Выберите файл"

     • Выберите ваш CSV файл с каталогом

     • Нажмите "Загрузить и проверить"

     • Дождитесь завершения проверки

     • Скачайте результат (Excel файл)

   ► Шаг 4: Остановка

     • Закройте браузер

     • Закройте черное окно консоли

  2. СПОСОБЫ ЗАПУСКА
═══════════════════════════════════════════════════════════════════════════

   ✓ РЕКОМЕНДУЕТСЯ: start_stable.bat

     • Самый надежный способ
     • Автоматически перезапускается при сбоях
     • Показывает подробную информацию в консоли
     • Используется ярлыком на рабочем столе

   ✓ ПРОСТОЙ: start.bat

     • Обычный запуск
     • Автоматически открывает браузер
     • Подходит для разовой работы

   ✓ СКРЫТЫЙ: start_hidden.vbs

     • Запускает сервер в фоне (без окна)
     • Автоматически открывает браузер
     • Для остановки нужно закрыть через диспетчер задач

  3. ЧАСТЫЕ ВОПРОСЫ
═══════════════════════════════════════════════════════════════════════════

   ❓ Что делать если не открывается сайт?

      • Подождите 5-10 секунд после запуска
      • Убедитесь что черное окно консоли открыто
      • Попробуйте обновить страницу в браузере (F5)
      • Проверьте что адрес: http://127.0.0.1:8080

   ❓ Черное окно закрылось само по себе

      • Это нормально если вы закончили работу
      • Если оно закрылось сразу - возможно ошибка
      • Запустите снова через start_stable.bat
      • Прочитайте сообщения в окне перед закрытием

   ❓ Ошибка "Порт 8080 уже используется"

      • Приложение уже запущено в другом окне
      • Закройте все окна консоли
      • Или перезагрузите компьютер
      • Запустите приложение заново

   ❓ Проверка очень долго идет

      • Это нормально для больших файлов (5-10 минут)
      • НЕ закрывайте браузер во время проверки
      • НЕ закрывайте черное окно консоли
      • Дождитесь появления кнопки "Скачать результат"

   ❓ Как остановить приложение?

      • Закройте браузер
      • Закройте черное окно консоли
      • Или нажмите Ctrl+C в черном окне
