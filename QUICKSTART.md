## Установка зависимостей

### Шаг 1: Установите Python

Убедитесь, что у вас установлен Python версии 3.8 или новее:

```bash
python --version
```

Если Python не установлен, скачайте его с [python.org](https://www.python.org/downloads/).

### Шаг 2: Установите Java (опционально)

Java нужна только для проверки орфографии через LanguageTool. Если её не установить, инструмент всё равно будет работать, но пропустит орфографические проверки.

**Windows:**
```bash
winget install Oracle.JDK.21
```

**macOS:**
```bash
brew install openjdk
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt-get install default-jre
```

Проверьте установку:
```bash
java --version
```

### Шаг 3: Установите Python зависимости

Откройте терминал в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

## Способ 1: Веб-интерфейс (рекомендуется)

Это самый простой способ использования инструмента.

### Шаг 1: Запустите веб-сервер

В терминале выполните:

```bash
python web_app.py
```

Вы увидите сообщение:
```
============================================================
🚀 Запуск веб-интерфейса Catalog Validator
============================================================
📍 Откройте браузер и перейдите по адресу:
   http://127.0.0.1:8080

📝 Для остановки сервера нажмите: Ctrl+C
============================================================
```

### Шаг 2: Откройте браузер

Перейдите по адресу: **http://127.0.0.1:8080**

Вы увидите веб-интерфейс с областью для загрузки файлов.

### Шаг 3: Загрузите CSV файл

1. Нажмите на область "Нажмите для выбора файла" или перетащите CSV файл в эту область
2. Выберите ваш CSV файл (с разделителем `;` и кодировкой `cp1251`)
3. Нажмите кнопку **"Запустить проверку"**

### Шаг 4: Дождитесь завершения

Обработка может занять от нескольких секунд до нескольких минут в зависимости от размера файла.

### Шаг 5: Скачайте результат

После завершения проверки появится кнопка **"Скачать результат"**. Нажмите её, чтобы скачать Excel файл с результатами.

### Шаг 6: Остановите сервер (когда закончите)

В терминале нажмите **Ctrl+C**, чтобы остановить веб-сервер.

## Способ 2: Командная строка

Для продвинутых пользователей и автоматизации.

### Шаг 1: Настройте конфигурацию

Откройте файл `check_catalog.py` и найдите секцию `CONFIG` (строки 44-62):

```python
CONFIG = {
    "input_file": "AZ_Игрушки_ru_RU_2025-11-18.csv",  # ← Укажите имя вашего файла
    "output_file": "AZ_Игрушки_ru_RU_2025-11-18_checked.xlsx",  # ← Имя выходного файла
    "sep": ";",
    "encoding": "cp1251",
    "case_consistency_threshold": 0.6,
}
```

Измените:
- `input_file` — имя вашего CSV файла
- `output_file` — желаемое имя Excel файла с результатами

### Шаг 2: Поместите CSV файл в папку проекта

Скопируйте ваш CSV файл в ту же папку, где находится `check_catalog.py`.

### Шаг 3: Запустите проверку

```bash
python check_catalog.py
```

### Шаг 4: Получите результат

После завершения в папке проекта появится Excel файл с именем, указанным в `output_file`.

## Формат входных данных

Ваш CSV файл должен:

- **Разделитель:** точка с запятой (`;`)
- **Кодировка:** Windows-1251 (cp1251)
- **Обязательные колонки:**
  - `category_level_1_name`, `category_level_2_name`, ... (до 5 уровней категорий)
  - `param_name` — название параметра товара
  - `value_name` — значение параметра
  - `param_id` — ID параметра (для группировки)

**Пример структуры CSV:**

```csv
category_level_1_name;category_level_2_name;param_name;value_name;param_id
Игрушки;Конструкторы;Цвет;Красный;101
Игрушки;Конструкторы;Цвет;Синий;101
Игрушки;Куклы;Материал;Пластик;102
```

## Что проверяется?

Инструмент автоматически проверяет:

1. **Орфографию и грамматику** (требует Java)
2. **Множественное число категорий** ("Игрушка" → "Игрушки")
3. **Имена собственные** (не трогает "Детский мир", "Apple", "iPhone 15")
4. **Единообразие регистра** в параметрах (все значения с маленькой или большой буквы)
5. **Паттерн "Другой"** с согласованием ("Другой цвет", "Другая форма")
6. **Единственное число** для значений параметров
7. **Однородность части речи** (прилагательные или существительные)

## Что делать, если что-то не работает?

### ❌ Ошибка: "ModuleNotFoundError: No module named 'pandas'"

**Решение:** Установите зависимости:
```bash
pip install -r requirements.txt
```

---

### ❌ Ошибка: "LanguageTool не запускается"

**Причина:** Не установлена Java.

**Решение:**
1. Установите Java (см. [Шаг 2: Установите Java](#шаг-2-установите-java-опционально))
2. Или продолжайте работу — инструмент будет работать без орфографических проверок

---

### ❌ Ошибка: "UnicodeDecodeError" при чтении CSV

**Причина:** Неправильная кодировка файла.

**Решение:**
1. Откройте CSV в Excel
2. Сохраните как CSV (разделитель — точка с запятой, кодировка — Windows-1251)
3. Или измените `encoding` в `CONFIG`:
   ```python
   "encoding": "utf-8",  # или "windows-1251"
   ```

---

### ❌ Веб-сервер не открывается в браузере

**Причина:** Порт 8080 занят другим приложением.

**Решение:** Измените порт в `web_app.py` (последняя строка):
```python
uvicorn.run(app, host="127.0.0.1", port=8081, log_level="info")  # ← Измените 8080 на 8081
```

Затем откройте: http://127.0.0.1:8081

---

### ❌ Файл не загружается в веб-интерфейс

**Проверьте:**
1. Файл имеет расширение `.csv`
2. Размер файла не слишком большой (< 100 МБ)
3. Формат соответствует требованиям (см. [Формат входных данных](#формат-входных-данных))

## Дополнительные возможности

### Использование LLM для анализа категорий (опционально)

Если у вас есть OpenAI API ключ, вы можете включить семантический анализ категорий:

1. Установите переменные окружения:

**Windows PowerShell:**
```powershell
$env:LLM_API_KEY="sk-your-openai-key"
$env:LLM_API_URL="https://api.openai.com/v1/chat/completions"
$env:LLM_MODEL="gpt-4-turbo"
```

**Linux/macOS:**
```bash
export LLM_API_KEY="sk-your-openai-key"
export LLM_API_URL="https://api.openai.com/v1/chat/completions"
export LLM_MODEL="gpt-4-turbo"
```

2. Запустите semantic service (в отдельном терминале):
```bash
uvicorn semantic_service:app --reload --port 8000
```

3. Установите URL для `check_catalog.py`:
```bash
$env:SEMANTIC_URL="http://127.0.0.1:8000/analyze-category"
```

4. Запустите проверку как обычно

---

### Пример 2: Обработка нескольких файлов

Создайте скрипт `batch_process.py`:

```python
import glob
from check_catalog import process_dataframe, write_with_highlight, CONFIG
import pandas as pd

for csv_file in glob.glob("data/*.csv"):
    print(f"Обработка: {csv_file}")
    df = pd.read_csv(csv_file, sep=";", encoding="cp1251", dtype=str)
    df_processed = process_dataframe(df)
    output = csv_file.replace(".csv", "_checked.xlsx")
    write_with_highlight(df_processed, output)
    print(f"✓ Готово: {output}")
```

Запустите:
```bash
python batch_process.py
```
